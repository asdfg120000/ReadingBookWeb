# 독서기록 서비스

작품을 검색해 개인 서재에 등록하고 독서기록 작성 / 관리 서비스

## 기술 스택

- Java 17
- Spring Boot 3.5
- Spring Data JPA
- Spring Security
- JWT
- MySQL
- Gradle

## 주요 기능

- 이메일 회원가입 및 로그인
- JWT Access Token 인증
- 작품 등록 및 제목·작가 검색
- 개인 서재 등록, 조회, 상태 변경, 삭제
- 독서기록 작성, 조회, 수정, 삭제
- 독서기록 공개·비공개 설정
- 공개 독서기록 조회
- kakao api를 연동해 원하는 책 정보 조회

## 실행 방법

- MySQL에 reading_db 데이터베이스를 생성
- 환경변수를 설정 ()RUN-> EDIT CONFIGURATION -> + ->

1. DB_USERNAME : MySQL 계정 
2. DB_PASSWORD : MySQL 비밀번호 
3. JWT_SECRET : 32바이트 이상의 무작위 비밀 문자열 (WINDOW POWERSHALL으로 확인)
4. KAKAO_REST_API_KEY: : KEY: 자체가 환경변수 이름
   https://developers.kakao.com/ 에서 회우너가입 후 회원가입 - 앱 - REST API 발급

- ReadingApplication -> >버튼 클릭

기본 주소: http://localhost:8080


## 인증

로그인 성공 시 Access Token을 발급 (1시간 후 자동 로그아웃)

인증이 필요한 요청의 헤더:


Authorization: Bearer {accessToken}


- 서명 알고리즘: HS256
- 토큰 유효기간: 1시간
- 만료 후 재로그인 필요
- 토큰 즉시 폐기 및 서버 측 로그아웃은 미구현

## 데이터 구조

- User: 회원 정보
- Work: 공통 작품 정보
- ShelfItem: 회원과 작품의 서재 등록 관계
- ReadingRecord: 회원이 작품에 작성한 독서기록


## 데이터 무결성

- 회원 이메일 UNIQUE 제약조건
- 작품 제목·작가 조합 UNIQUE 제약조건
- 회원·작품 서재 등록 조합 UNIQUE 제약조건
- 서비스 중복 검사와 DB 제약조건을 함께 적용

## 접근 권한

- 작품 검색 및 공개 독서기록 조회: 비회원 허용
- 작품 등록 및 개인 기능: 로그인 필요
- 서재 변경·삭제: 소유자만 허용
- 독서기록 수정·삭제·공개 설정: 작성자만 허용
- 비공개 독서기록: 작성자만 조회 가능
